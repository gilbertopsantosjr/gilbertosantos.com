## 🎨 Design System

### Color Palette

**Primary Colors**:
- Royal: #4C40F7 (main brand color for CTAs, links, emphasis)
- Royal Light: #6B61FF (hover states, gradients)
- Royal Dark: #3A30C5 (active states)

**Neutral Colors**:
- White: #FFFFFF (main content backgrounds)
- Light Gray: #F5F6F8 (alternating section backgrounds)
- Cool Gray: #E8EAEF (borders, dividers)
- Medium Gray: #8B92A8 (secondary text)
- Charcoal: #2D3142 (primary text, headings)
- Navy Dark: #1A1D2E (footer background)

**Accent Colors**:
- Soft Purple: #E8E6FF (decorative backgrounds, tags)
- Soft Peach: #FFE8D6 (warm accents, blobs)
- Soft Yellow: #FFF9E6 (highlights)
- Soft Green: #E6F9F5 (success states)
- Coral: #FF6B6B (warnings)
- Orange: #FF9054 (secondary accents)

### Typography

**Font Families**:
- Headings: DM Sans, Inter, or Plus Jakarta Sans (weights: 600-700 for main, 500-600 for sub)
- Body: DM Sans or Inter (weights: 400 normal, 500 emphasis, 600 labels)

**Type Scale**:
- Hero H1: clamp(2.5rem, 5vw, 3.5rem), line-height: 1.15, letter-spacing: -0.02em, weight: 700
- H2: clamp(1.75rem, 4vw, 2.5rem), line-height: 1.2, letter-spacing: -0.01em, weight: 700
- H3: 1.5rem, line-height: 1.3, weight: 600
- H4: 1.125rem, line-height: 1.4, weight: 600
- Body: 1rem, line-height: 1.6, weight: 400
- Small: 0.875rem, line-height: 1.5, weight: 400

### Spacing

**Philosophy**: Generous whitespace creates breathing room and improves content digestibility.

- Section Padding: clamp(60px, 8vw, 100px) vertical, clamp(24px, 5vw, 80px) horizontal
- Container Max Width: 1280px
- Between Sections: clamp(40px, 6vw, 80px)
- Between Heading and Content: 32px - 48px
- Between Cards: 24px - 32px
- Inside Cards: 24px - 32px
- Grid Gutter: 24px - 32px

### Components

**Buttons**:
- Primary: #4C40F7 background, white text, 8px border-radius, 14px 28px padding
  - Hover: #6B61FF background, translateY(-2px), shadow: 0 4px 12px rgba(76, 64, 247, 0.3)
  - Transition: all 0.3s ease
- Secondary: transparent background, #4C40F7 text and 1.5px border, 8px border-radius, 14px 28px padding

**Cards**:
- Default: white background, 16-20px border-radius, 24-32px padding
  - Shadow: 0 2px 8px rgba(0, 0, 0, 0.04), 0 4px 16px rgba(0, 0, 0, 0.06)
  - Border: 1px solid rgba(0, 0, 0, 0.06)
- Hover: translateY(-4px), shadow: 0 8px 24px rgba(0, 0, 0, 0.12)
  - Transition: all 0.35s cubic-bezier(0.4, 0, 0.2, 1)

**Icons**:
- Use Font Awesome (line-based, stroke weight 1.5-2)
- Sizes: 20px small, 24px default, 32px large, 40-48px feature
- Containers: #F5F6F8 or accent color backgrounds, 12-16px border-radius, 12-16px padding

**Badges**:
- Background: #4C40F7, white text, 6px border-radius, 4px 10px padding
- Font: 0.6875rem, weight 600, uppercase, letter-spacing: 0.03em
- Tag Variant: #E8E6FF background, #4C40F7 text

### Animations

**Philosophy**: Subtle and smooth. Animations enhance UX without being distracting.

- Fade In Up: opacity 0→1, y: 30px→0, duration: 0.6-0.8s, easing: cubic-bezier(0.4, 0, 0.2, 1)
- Hover Lift: translateY(-4px), duration: 0.35s, easing: ease-out
- Stagger: 0.1-0.15s delay between items
- Scale: scale(1.02), duration: 0.3s for button hovers

### Background Patterns

Alternate between:
- White (#FFFFFF) and Light Gray (#F5F6F8) for sections
- Subtle grid/circuit/dot SVG patterns (low opacity 0.05-0.12)
- Soft gradient mesh overlays using accent colors
- Decorative blobs: soft organic shapes in accent colors at 20-40% opacity, heavy blur

## 🛠️ Technical Requirements

### Framework & Stack
- **Next.js 15+** with App Router
- TypeScript
- Tailwind CSS for styling
- Framer Motion for animations
- Font Awesome icons (React component)

### Performance & SEO
- Static generation where possible
- Optimized images (next/image or WebP format)
- Semantic HTML5 structure
- Comprehensive meta tags (Open Graph, Twitter Cards)
- Structured data for rich snippets
- Fast page load (<2s)
- Core Web Vitals optimization

### SEO Meta Data
```
Title: Gilberto Santos | Software Engineer Consultant - Turn Your Idea Into Scalable Micro-SaaS

Description: Principal Software Engineer with 18+ years of experience helping founders turn ambitious ideas into fast, scalable cloud products. AWS Certified Solutions Architect specializing in microservices, serverless platforms, and enterprise-grade software.

Keywords: software engineer consultant, micro saas development, aws solutions architect, mvp development, saas architecture, cloud native development, microservices consultant, technical co-founder, principal engineer, serverless development
```

### Responsive Breakpoints
- Mobile: < 640px (single column stacking)
- Tablet: 640px - 1024px
- Desktop: > 1024px
- Widescreen: > 1440px

### Accessibility
- WCAG 2.1 AA compliant
- Minimum 4.5:1 contrast for body text
- Visible focus indicators
- Minimum 44x44px touch targets
- Respect prefers-reduced-motion
- Semantic HTML with proper heading hierarchy
- Alt text for all images
- Keyboard navigation support

### Animations
- Fade in up on scroll for sections (Intersection Observer)
- Smooth hover transitions on all interactive elements
- Staggered animations for card grids (0.1-0.15s delay)
- Parallax effect on hero section (optional)
- Smooth scroll for anchor links

### Conversion Optimization
- Above-the-fold CTAs visible immediately
- Trust signals near every CTA
- Clear value proposition in first 5 seconds
- Social proof strategically placed
- Reduced friction in conversion path
- Mobile-optimized CTAs (larger touch targets)

## 💡 Design Philosophy

**Avoid**:
- Visual clutter or dense layouts
- Harsh contrasts or overwhelming patterns
- Aggressive sales language
- Generic stock photos or emojis
- Freelancer/portfolio aesthetics

**Embrace**:
- Generous whitespace and breathing room
- Soft, sophisticated color palette
- Conversion-focused structure
- Premium fintech aesthetic
- Professional photography
- Subtle, purposeful animations
- Clear hierarchy and scannable content

## 🚀 Implementation Notes

1. **Start with mobile-first** responsive design
2. **Use semantic HTML** for SEO (header, nav, main, section, article, footer)
3. **Lazy load images** below the fold
4. **Inline critical CSS** for first paint
5. **Preload fonts** to prevent FOUT
6. **Use CSS Grid/Flexbox** for layouts, not floats
7. **Optimize SVGs** for small file sizes
8. **Test on real devices** for touch interactions
9. **A/B test CTA variations** after launch
10. **Monitor Core Web Vitals** in production
